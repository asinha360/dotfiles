> why does MTBF grow exponentially with resolve time?
⏺ A metastable flop leaves the balanced point at a rate set by its time constant τ: the chance it is still unresolved after time t falls as e^(−t/τ).
MTBF = e^(t_r/τ) / (T₀ · f_clk · f_data)
Each extra flop adds about one clock period to t_r, so MTBF multiplies by roughly e^(T_clk/τ) per stage.
